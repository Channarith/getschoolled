LESSON: IT Fundamentals
LANGUAGE: en

SLIDE 1 | What IT Professionals Do
Information Technology professionals design, build, maintain, and support the technology systems that organizations depend on — from the laptop on every desk to the global network connecting them. IT encompasses four broad domains: infrastructure (networks, servers, data centers), end-user support (helpdesk, device management), software development (building custom applications), and security (protecting systems and data). IT support specialists resolve everyday technical problems for users — password resets, software installations, network connectivity issues — and are often the first career step for professionals who go on to specialize in networking, cloud, security, or systems administration. Understanding the full IT landscape early helps you make informed decisions about which specialization aligns with your strengths and interests.
NARRATION: IT professionals span infrastructure, support, development, and security — understanding all four domains helps you choose the right specialization early in your career.

SLIDE 2 | Computer Hardware Fundamentals
Computer hardware refers to the physical components that make up a computing system, and understanding what each component does is essential for diagnosing problems, recommending upgrades, and managing hardware inventory. The CPU (Central Processing Unit) is the brain of the computer, executing instructions; modern CPUs have multiple cores (physical processors on one chip) and threads that enable parallel task execution — more cores generally mean better multitasking performance. RAM (Random Access Memory) is the workspace where the CPU loads currently running programs; insufficient RAM causes a computer to use the much-slower storage drive as overflow (virtual memory), dramatically degrading performance. Storage comes in three main types: traditional HDDs (mechanical spinning disk, cheap, slow, fragile) are largely replaced by SSDs (flash memory, 5–10x faster) and NVMe SSDs (connect directly to the CPU via PCIe, 10–30x faster than HDD) for system drives.
NARRATION: The CPU processes instructions, RAM provides working memory for active programs, and NVMe SSDs deliver dramatically faster storage than traditional hard drives.

SLIDE 3 | Motherboard, GPU, and Power Supply
The motherboard is the main circuit board that physically and electrically connects every component — CPU, RAM, storage, GPU, and peripherals — and its chipset determines which CPUs, RAM types, and expansion cards are compatible. The GPU (Graphics Processing Unit) was originally designed for rendering 3D graphics but is now equally important for AI/ML training, video encoding, and scientific computing; integrated GPUs share the CPU's RAM, while discrete GPUs have their own dedicated VRAM and PCIe slot. The power supply unit (PSU) converts AC mains power to the DC voltages components require, and its wattage rating must exceed the combined power draw of all components with headroom for peaks — a system with a high-end CPU and GPU may require a 750W to 1000W PSU. When troubleshooting a computer that won't power on, the PSU is one of the first components to test or swap, as failures are common and symptoms are non-specific.
NARRATION: The motherboard connects all components, the GPU handles graphics and AI workloads, and the power supply must be sized adequately for all components combined.

SLIDE 4 | Operating Systems: Windows, macOS, and Linux
An operating system (OS) manages hardware resources and provides a platform for applications to run, acting as the intermediary between user-facing software and the physical components below. Windows dominates corporate desktop environments with approximately 70% market share, Active Directory integration, Group Policy management, and extensive enterprise software compatibility. macOS is Unix-based, runs only on Apple hardware, and is preferred in creative industries (design, video, music) and software development for its stability, quality display rendering, and developer tooling. Linux powers the majority of web servers, cloud infrastructure, and embedded systems worldwide; there are hundreds of distributions (distros) — Ubuntu and Debian for general use, Red Hat Enterprise Linux (RHEL) and CentOS for enterprise servers, Kali for security — all sharing a common kernel but differing in package managers, default tools, and target use cases.
NARRATION: Windows leads corporate desktops, macOS dominates creative industries, and Linux runs the majority of servers and cloud infrastructure worldwide.

SLIDE 5 | File Systems: NTFS, ext4, and APFS
A file system organizes how data is stored, named, and retrieved on a storage device — without it, a drive is just an unstructured sequence of ones and zeros. NTFS (New Technology File System) is Windows's default file system, supporting file permissions, journaling (crash recovery), encryption (BitLocker), and files larger than 4GB — FAT32 (limited to 4GB files) is still used for bootable USB drives and compatibility with non-Windows systems. ext4 is the default Linux file system, offering journaling, large file support, and efficient use of large storage volumes; it is not natively readable by Windows without third-party drivers. APFS (Apple File System) is the default for macOS and iOS devices from 2017 onward, built for SSDs with features like copy-on-write (snapshots), native encryption, and efficient file cloning that makes duplicating large files almost instantaneous.
NARRATION: NTFS serves Windows, ext4 serves Linux, and APFS serves Apple devices — each file system is optimized for its platform with distinct capabilities and limitations.

SLIDE 6 | Process Management and the Task Manager
Every running program on a computer is a process — an instance of a program loaded into memory with allocated CPU time and resources. The Windows Task Manager (Ctrl+Shift+Esc) provides a real-time view of all running processes, their CPU, memory, disk, and network usage, enabling you to identify what is causing slowness (a runaway process consuming 90% CPU) and terminate unresponsive applications. The Performance tab in Task Manager shows historical CPU, memory, disk, and network utilization graphs and reveals hardware bottlenecks — consistently maxed-out RAM indicates the system needs more memory. On Linux, the `top` or `htop` command provides equivalent functionality, while `ps aux` lists all running processes and their PIDs (process IDs), enabling you to kill a specific process with `kill -9 <PID>` when it won't terminate normally.
NARRATION: Task Manager and top give you real-time visibility into which processes are consuming resources, enabling you to diagnose slowdowns and terminate frozen applications.

SLIDE 7 | Networking Basics: IP Addresses, Subnets, DHCP, and DNS
A network is a collection of devices that communicate with each other, and every device needs a unique identifier (IP address) to send and receive data. IPv4 addresses are 32-bit numbers written in dotted-decimal notation (192.168.1.100) and divided into network and host portions by a subnet mask (255.255.255.0 or /24 in CIDR notation) — the subnet defines which addresses can communicate directly without a router. DHCP (Dynamic Host Configuration Protocol) automatically assigns IP addresses to devices when they join a network, eliminating the need to manually configure each device; most home routers run a DHCP server by default. DNS (Domain Name System) translates human-readable domain names (google.com) into IP addresses that computers use to route traffic — it is often called the "phone book of the internet," and DNS failures are among the most common causes of what users experience as "the internet is down."
NARRATION: IP addresses identify every device on a network, DHCP assigns them automatically, and DNS translates domain names into the IP addresses computers actually use.

SLIDE 8 | Network Devices: Routers, Switches, and Access Points
Understanding what each network device does prevents misdiagnosis when troubleshooting connectivity problems. A router connects different networks together — most commonly, your local network to the internet — and makes forwarding decisions based on IP addresses, maintaining a routing table of known paths. A switch connects devices within the same local network and makes forwarding decisions based on MAC addresses (physical hardware addresses), operating at Layer 2 of the OSI model; managed switches support VLANs (Virtual LANs) that segment a network into isolated logical groups without separate physical cabling. A wireless access point (AP) extends the network wirelessly, and most consumer home routers combine router, switch, and access point into a single device. A hub (legacy, rarely seen today) broadcasts all incoming traffic to every connected port — unlike a switch, which delivers traffic only to the intended recipient — creating unnecessary network congestion.
NARRATION: Routers connect networks using IP addresses, switches connect devices within a network using MAC addresses, and access points extend the network wirelessly.

SLIDE 9 | The OSI Model: Seven Layers
The OSI (Open Systems Interconnection) model is a conceptual framework that standardizes how network communication is divided into seven functional layers, each with a specific responsibility — understanding it lets you pinpoint where a problem is occurring in any network issue. Layer 1 (Physical) is the raw transmission medium: cables, Wi-Fi radio signals, fiber optics. Layer 2 (Data Link) handles framing and MAC address-based delivery within a local network — this is where switches operate. Layer 3 (Network) handles IP addressing and routing between networks — this is where routers operate. Layer 4 (Transport) manages end-to-end communication reliability with TCP (guaranteed delivery) or UDP (best-effort). Layers 5-6 (Session and Presentation) manage connections and data formatting. Layer 7 (Application) is what users interact with — HTTP, DNS, FTP, SMTP, and HTTPS operate here, and most application-level troubleshooting starts at this layer.
NARRATION: The OSI model's seven layers let you narrow down network problems to a specific layer — from cable faults at Layer 1 to application configuration errors at Layer 7.

SLIDE 10 | TCP vs UDP and Common Ports
TCP (Transmission Control Protocol) establishes a connection through a three-way handshake (SYN, SYN-ACK, ACK), guarantees packet delivery with acknowledgments and retransmission, and ensures data arrives in order — making it ideal for web browsing, email, and file transfers where data integrity is critical. UDP (User Datagram Protocol) is connectionless and sends packets without confirmation of receipt, sacrificing reliability for speed — it is used for video streaming, DNS queries, online gaming, and VoIP where a dropped packet is less damaging than a delay. Memorizing common port numbers is essential for IT work: HTTP (80), HTTPS (443), SSH (22), FTP (20/21), SMTP (25), DNS (53), RDP (Remote Desktop Protocol, 3389), and LDAP (389). In troubleshooting, knowing that a user can't reach a web server on port 80 but can reach it on port 443 immediately narrows the problem to HTTP-specific configuration rather than network connectivity.
NARRATION: TCP guarantees reliable delivery for critical data, UDP prioritizes speed for real-time applications, and memorizing common port numbers accelerates network troubleshooting.

SLIDE 11 | Wireless Networking: Wi-Fi Standards and Security
Wi-Fi standards, defined by the IEEE 802.11 family, have evolved significantly over time, with each generation increasing speed, range, and efficiency. 802.11ac (Wi-Fi 5) operates on the 5GHz band and delivers throughput up to 3.5 Gbps in ideal conditions; 802.11ax (Wi-Fi 6/6E) adds OFDMA (Orthogonal Frequency Division Multiple Access) technology that dramatically improves performance in dense environments with many simultaneous devices, making it the standard for new enterprise and home deployments. The SSID is the network name that appears in the device's Wi-Fi list; hiding the SSID provides minimal security (any network analyzer reveals it immediately) and causes more helpdesk calls than it prevents. WPA3 (Wi-Fi Protected Access 3) is the current security standard, replacing WPA2 with individualized data encryption (each session uses a unique key) and protection against offline dictionary attacks — ensuring all access points support WPA3 is a straightforward security improvement.
NARRATION: Wi-Fi 6 improves performance in dense environments, and upgrading to WPA3 provides individualized session encryption that protects against password-cracking attacks.

SLIDE 12 | Cloud Computing: IaaS, PaaS, SaaS
Cloud computing delivers computing resources — servers, storage, databases, networking, software — over the internet on a pay-as-you-use model, eliminating the capital expense and operational overhead of managing physical infrastructure. Infrastructure as a Service (IaaS) provides raw compute, storage, and networking that customers configure themselves — AWS EC2, Azure Virtual Machines, and Google Compute Engine are IaaS products where you manage the OS and everything above it. Platform as a Service (PaaS) provides a managed environment for developing and deploying applications without managing the underlying infrastructure — AWS Elastic Beanstalk, Azure App Service, and Heroku handle server patching, scaling, and availability automatically. Software as a Service (SaaS) delivers fully managed applications accessed via browser or API — Microsoft 365, Salesforce, Zoom, and Slack are all SaaS; the vendor manages everything from infrastructure to application updates.
NARRATION: IaaS gives you raw infrastructure to configure, PaaS gives you a managed application platform, and SaaS gives you a fully managed application you just use.

SLIDE 13 | Virtualization: VMs, Hypervisors, and Containers
Virtualization allows multiple virtual computers to run on a single physical host, dramatically improving hardware utilization and enabling fast provisioning of new environments without buying physical servers. A hypervisor is the software layer that manages virtual machines (VMs) by allocating physical CPU, RAM, storage, and network resources; Type 1 (bare-metal) hypervisors like VMware ESXi, Microsoft Hyper-V, and KVM run directly on hardware for maximum performance and are used in enterprise data centers. Type 2 (hosted) hypervisors like VirtualBox and VMware Workstation run as applications on top of an existing OS and are ideal for development and testing on a personal laptop. Containers (Docker, Kubernetes) are lighter than VMs — they share the host OS kernel rather than virtualizing an entire operating system — resulting in faster startup (seconds vs. minutes), smaller size, and higher density, but with less isolation between containers than VMs provide.
NARRATION: Type 1 hypervisors run enterprise virtualization on bare metal, while containers share the host kernel to achieve faster startup and higher density than full VMs.

SLIDE 14 | Troubleshooting Methodology
Effective troubleshooting is a systematic discipline, not guesswork — following a consistent methodology resolves issues faster and prevents accidentally creating new problems while fixing the original one. The CompTIA troubleshooting model has six steps: Identify the problem (gather information, ask when it started and what changed), Establish a theory (hypothesize probable causes), Test the theory (confirm or rule it out), Establish an action plan, Implement the solution, and Verify and document results. Isolating variables is critical: when a user can't access a specific website but can access others, you know the problem is not network connectivity — it narrows to DNS resolution, the specific server, or a firewall rule. Documentation of every troubleshooting step matters both for the current ticket and for the knowledge base that helps the next technician resolve the same issue faster.
NARRATION: Systematic troubleshooting — identifying, isolating, testing one variable at a time, and documenting — resolves issues faster than guessing and produces knowledge base articles that prevent repeat calls.

SLIDE 15 | Windows Administration: Users, Group Policy, and Event Viewer
Windows administration tasks that every IT professional encounters include managing local and domain user accounts, applying configuration via Group Policy, and diagnosing problems through Event Viewer logs. Local user accounts are managed through Computer Management (compmgmt.msc) or the Settings app; domain accounts in enterprise environments are managed through Active Directory Users and Computers (ADUC). Group Policy Objects (GPOs) allow administrators to enforce settings across hundreds of machines simultaneously — blocking USB storage, mapping network drives, setting desktop wallpaper, enforcing screen lock timeouts, and deploying software — without touching each machine individually. Event Viewer (eventvwr.msc) records system, security, and application events; filtering the Security log for Event ID 4625 (failed logon) can quickly reveal brute-force attempts, while System log errors with source "Disk" may indicate impending storage failure.
NARRATION: Group Policy lets administrators enforce settings across hundreds of machines simultaneously, and Event Viewer security logs reveal failed login attempts and other suspicious activity.

SLIDE 16 | Linux Command Line Basics
The Linux command line (shell, typically bash or zsh) gives IT professionals powerful control over systems and is essential for server administration, scripting, and most cybersecurity tools. Navigation commands: `ls` lists directory contents, `cd <directory>` changes directory, `pwd` prints the current directory path, and `find / -name "filename"` searches the entire filesystem for a file by name. File operations: `cp source destination` copies files, `mv source destination` moves or renames files, `rm filename` removes a file (permanently, with no recycle bin), and `mkdir <name>` creates a new directory. `grep "pattern" filename` searches text within files and is indispensable for log analysis; `ps aux` lists all running processes; `chmod 755 filename` sets file permissions (owner can read/write/execute, others can read/execute); and `sudo command` runs a command with root (administrator) privileges.
NARRATION: Mastering ls, cd, grep, chmod, ps, and sudo gives you the foundational Linux command-line skills needed for server administration and most IT roles.

SLIDE 17 | Active Directory and User Management
Active Directory (AD) is Microsoft's directory service for Windows domain networks, acting as the central authentication and authorization store for users, computers, and groups in an organization. Every employee has a domain account in AD (username@company.com) used to log in to any domain-joined computer, access shared drives, and authenticate to enterprise applications — creating, modifying, and deactivating these accounts is one of the most frequent helpdesk tasks. Organizational Units (OUs) are containers within AD that organize objects (users, computers, groups) into a hierarchy mirroring the company's structure, enabling Group Policy to be applied to specific departments or locations. When a user leaves the organization, the security protocol is to disable their account immediately (not delete it — deletion loses group memberships and email), change passwords on shared service accounts they had access to, and revoke any multi-factor authentication tokens.
NARRATION: Active Directory is the backbone of enterprise user management, and following proper offboarding procedures — disabling accounts immediately — is one of the most critical security processes in IT.

SLIDE 18 | Backup and Disaster Recovery: The 3-2-1 Rule
Data backup is a non-negotiable IT responsibility — ransomware attacks, hardware failures, accidental deletions, and natural disasters all result in data loss that is catastrophic without functional backups. The 3-2-1 backup rule states: maintain 3 copies of data (production plus two backups), store them on 2 different media types (e.g., local NAS drive and cloud storage), and keep 1 copy offsite — ensuring no single failure (fire, flood, ransomware that encrypts network shares) destroys all copies simultaneously. Recovery Time Objective (RTO) defines the maximum acceptable downtime after a disaster — how long the business can operate without the system. Recovery Point Objective (RPO) defines the maximum acceptable data loss — if RPO is 4 hours, backups must run at least every 4 hours. Testing backup restoration (not just backup creation) is the step most organizations skip, and it is the step that reveals whether backups are actually usable.
NARRATION: The 3-2-1 backup rule and regular restoration testing ensure you can actually recover from disaster — a backup you've never tested is not a backup you can rely on.

SLIDE 19 | IT Ticketing Systems and Service Management
IT ticketing systems (also called help desk or service desk platforms) track every user request, incident, and change in a single system, enabling workload visibility, accountability, and performance measurement. ServiceNow is the enterprise-standard IT Service Management (ITSM) platform, offering incident management, change management, asset management, and a self-service portal; it is the platform you'll encounter in most large enterprises. Jira Service Management (formerly Jira Service Desk) is popular in software-focused companies that already use Jira for engineering project management, offering tight integration between IT tickets and development work. Good ticket hygiene matters for career growth: every ticket should have a clear description of the issue, steps taken to investigate, the resolution, and the root cause — this information builds the knowledge base that reduces repeat incidents and demonstrates your diagnostic thinking to senior colleagues and managers.
NARRATION: Ticketing systems create accountability and visibility for IT work, and thorough ticket documentation builds the team knowledge base that reduces repeat incidents over time.

SLIDE 20 | The ITIL Framework
ITIL (Information Technology Infrastructure Library) is the most widely adopted framework for IT service management, providing a structured set of practices for delivering and improving IT services that align with business needs. The ITIL lifecycle covers Service Strategy, Service Design, Service Transition, Service Operation, and Continual Service Improvement — but the concepts IT professionals encounter most daily are in Service Operation. An Incident is any unplanned interruption to a service (printer not working, email down, website unreachable); the goal is to restore service as quickly as possible. A Problem is the underlying root cause of one or more incidents; problem management investigates why incidents keep recurring and eliminates the cause. Change Management ensures that modifications to IT systems follow an approval and communication process that minimizes risk — the "unauthorized change" is the root cause of roughly 80% of outage postmortems.
NARRATION: ITIL's distinction between incidents (restore service now) and problems (eliminate the root cause) is the most practical framework concept for day-to-day IT operations.

SLIDE 21 | Mobile Device Management and BYOD
Mobile Device Management (MDM) software enables IT to centrally enroll, configure, secure, monitor, and wipe mobile devices — essential when employees carry smartphones and tablets that access corporate email, documents, and applications. Enterprise MDM platforms (Microsoft Intune, Jamf, VMware Workspace ONE) can enforce PIN/biometric lock requirements, require device encryption, push configuration profiles and applications, restrict what apps can be installed, and remotely wipe a device if it is lost or stolen. BYOD (Bring Your Own Device) policies allow employees to use personal devices for work, reducing hardware cost but creating complex security and privacy challenges — employees rightfully object to employers having the ability to wipe their personal photos and messages. Most organizations address this with containerization: MDM creates an encrypted corporate container on the personal device (controlling only corporate data within it) rather than managing the entire device, respecting employee privacy while protecting corporate data.
NARRATION: MDM platforms enforce security policies on mobile devices and enable remote wipe, while containerization balances corporate data protection with employee privacy on personal devices.

SLIDE 22 | Printer and Peripheral Troubleshooting
Printers generate a disproportionate share of IT helpdesk tickets relative to their complexity, and a systematic approach resolves most issues quickly. The first step is always to check the obvious: is the printer powered on, online (not showing "Offline" status), connected to the network or USB, and does it have paper and toner? Windows printer issues often resolve by clearing the print spooler (stop the spooler service, delete files in C:\Windows\System32\spool\PRINTERS, restart the spooler) — a jammed print queue is the most common cause of a printer that appears online but won't print. Network printers require a static IP address (or a DHCP reservation by MAC address) — a printer that gets a different IP address after a power cycle will stop working for all users who mapped it by IP. Driver mismatches cause formatting issues, color problems, and feature unavailability; always download the current driver from the manufacturer's website rather than relying on Windows-included generic drivers.
NARRATION: Most printer problems trace to offline status, jammed print queues, changed IP addresses, or driver mismatches — checking these four things systematically resolves the majority of tickets.

SLIDE 23 | Documentation and Knowledge Base Writing
IT documentation is one of the highest-leverage investments a team can make: a well-written runbook or knowledge base article can resolve an issue in minutes that would otherwise take an hour and a senior technician. Good IT documentation has four properties: it is accurate (reflects the current state of the system, not how it was configured three years ago), discoverable (searchable by the terms a technician would naturally use), actionable (step-by-step instructions with exact commands, not vague descriptions), and maintained (a documentation owner updates it when procedures change). Standard documentation types include step-by-step procedures (how to add a user to Active Directory), runbooks (what to do when a specific alert fires), architecture diagrams (how systems connect and depend on each other), and postmortem reports (what failed, why, what was done, and what changes prevent recurrence). Platforms like Confluence, Notion, and IT Glue are purpose-built for IT documentation and knowledge management.
NARRATION: Accurate, searchable, step-by-step documentation multiplies your team's capacity by letting any technician resolve issues that previously required senior expertise.

SLIDE 24 | IT Certifications Roadmap
Certifications validate your skills to employers and are particularly important in IT because many roles require specific credentials or use them as minimum screening criteria. CompTIA A+ (two exams: Core 1 and Core 2) is the foundational IT certification covering hardware, operating systems, networking basics, troubleshooting, and security for end-user devices — it is the standard qualification for helpdesk and desktop support roles and satisfies DoD baseline requirements. CompTIA Network+ validates networking knowledge — protocols, topologies, troubleshooting, security concepts — and is the appropriate next step after A+. CompTIA Security+ validates security fundamentals and is often required for IT roles with any security responsibility. Google's IT Support Professional Certificate on Coursera is an accessible entry point for career changers with no prior IT background; it covers similar ground to A+ and is widely recognized by employers who partner with Google on the program.
NARRATION: The CompTIA A+, Network+, and Security+ certification stack provides a structured, employer-recognized pathway from IT helpdesk into networking and security specializations.

SLIDE 25 | Customer Service Skills for IT Helpdesk
Technical skills get you into an IT helpdesk role, but customer service skills determine how quickly you advance — the ability to communicate clearly with non-technical users under pressure is consistently rated by IT managers as the most important quality they look for. Active listening means fully understanding the user's description of the problem before jumping to solutions; interrupting users to apply a fix before understanding the full context is the most common mistake new technicians make. Using plain language (avoiding jargon like "the DNS resolver is caching a stale A record" in favor of "your computer has an outdated address saved for that website") reduces user frustration and builds confidence that the issue is being handled competently. Managing expectations — telling users upfront how long a resolution will take and proactively updating them if it takes longer — reduces callbacks and escalations more than any technical improvement.
NARRATION: Active listening, plain language, and proactive communication are the customer service skills that separate good IT technicians from great ones — technical ability alone is not enough.

SLIDE 26 | Career Progression in IT
IT offers one of the most navigable career ladders of any technical field, with clear entry points, recognized progression milestones, and diverse specialization paths that suit different strengths. The typical progression begins at Tier 1 (Level 1) Helpdesk, handling password resets, basic software support, and hardware swaps — the volume of tickets here builds troubleshooting speed and customer communication skills faster than any training course. Tier 2 support handles escalated issues requiring deeper technical knowledge: network configuration, server access, application troubleshooting, and MDM management. Progression from there branches into Systems Administration (managing servers and enterprise infrastructure), Network Administration, Cloud Engineering, Security, or DevOps. Certifications accelerate progression at each stage, but demonstrated impact — reducing ticket resolution time, building a knowledge base that lowers repeat calls, or automating a manual process — is what consistently earns promotions in IT.
NARRATION: IT careers progress from helpdesk to systems or network administration then into cloud, security, or DevOps specializations — demonstrated impact and certifications both drive advancement.
