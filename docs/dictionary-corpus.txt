Dictionary + voice corpus (EN + Khmer)
======================================

Self-hosted lexicon pipeline: open baselines → staging → review → content packs
→ progressive read-aloud trainer → CosyVoice raw audio → noise-filter crisp/gold.

Owned by the Theodore RAG lab (subrepos/theodore_rag_lab, port 8095).
Repo-root scripts/dictionary/* are thin shims into the lab.

No paid TTS/LLM APIs required. edge-tts / ElevenLabs must never be marked gold.

Lab console
-----------
  . .venv/bin/activate
  python3 -m pip install -e 'packages/shared' -e 'subrepos/theodore_rag_lab[test]'
  PYTHONPATH=subrepos/theodore_rag_lab/src:packages/shared/src \
    python3 -m uvicorn theodore_rag_lab.main:app --port 8095 --host 127.0.0.1

  Open http://127.0.0.1:8095/ → tab "Corpus + read-aloud"
  Or CLI:
    theodore-rag-corpus-update
    theodore-rag-read-aloud --heard "She walked to school."
  Shims (same behavior):
    python3 scripts/dictionary/train_update.py
    python3 scripts/dictionary/read_aloud.py --heard "She walked to school."

Layout (AOEP_DICTIONARY_DIR, default ~/.cache/aoep/dictionary)
-------------------------------------------------------------
  baselines/     wordfreq, WordNet glosses, CMUdict, Wiktionary extract, Tatoeba, Khmer snapshot
  staging/       en.jsonl km.jsonl
  review/        queue.jsonl feedback.json
  sentences/     curriculum JSONL
  progress/      per-learner mastery
  audio/{lang}/raw|crisp/
  export/        vocabulary + slang packs + dictionary_llm_train.jsonl

LLM training bridge
-------------------
  Approved/auto staging rows feed aoep_shared.llm_training.assemble as source
  "dictionary" (auto-scanned from AOEP_DICTIONARY_DIR). Export explicitly:

    curl -s -X POST http://127.0.0.1:8095/api/corpus/export-llm | python3 -m json.tool

  Then assemble in the LLM lab (:8019) / training/run_finetune.py on a GPU host.

-----------------

Audio cleanup
-------------
  Raw CosyVoice or mic takes → clean (high-pass, denoise, gate/trim, normalize).
  Only crisp/gold clips are fine-tune eligible.

Scale CosyVoice fine-tune data from video
-----------------------------------------
  The language pools (Khmer, Mandarin, Cantonese, English, Spanish, and the
  rest of urls/cosyvoice_channels.json) are the voice-training queue. The RAG
  lab Voice training tab and the command line run the same code. Progress is
  output/cosyvoice_voice_queue_status.json. A WAV already on disk is skipped.

  Drop links, files, and databases (UI or CLI, same intake)
  -------------------------------------------------------
  RAG lab → Drop training. Drag a link, video, audio file, channel, Vimeo URL,
  news link, note, CSV, JSON, or SQLite database onto the page. The shell takes
  the same things as arguments (drag the files onto the command before Enter):

    python3 scripts/training_drop.py ./lesson.mp4 ./school.db @ChinesePodTV
    python3 scripts/training_drop.py --stdin
    python3 scripts/training_drop.py --train --max-urls 2 <urls and files>

  YouTube and Vimeo go to output/intake/voice/urls.txt (a channel is listed up
  to the channel cap, default 20). Audio and video files go to
  output/intake/voice/media/. Notes, news links, and database rows go to
  output/intake/rag/ and are added to the lab index. Question/answer rows also
  append to output/intake/llm/dropped_rag.jsonl. Train dropped voice ingests
  only that bucket.

  UI: http://127.0.0.1:8095/ → Voice training
  CLI:
    theodore-rag-voice-queue --pool es,th --workers 2 --max-urls 2
    python3 scripts/cosyvoice_batch_ingest.py --pool es,th --workers 2 --max-urls 2
    theodore-rag-voice-queue --stop

  One channel file on its own:
    python3 scripts/cosyvoice_ingest.py --urls-file urls.txt --language en \
      --output-dir output/cosyvoice_en

  Merged recipes land in output/cosyvoice_<pool>_merged. See docs/cosyvoice-a2f.txt.
