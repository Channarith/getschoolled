Webcam recognition lab (private sub-repo)
=========================================

Location: labs/webcam-recognition-suite/  (PRIVATE — see PRIVATE.txt)

What it covers
  - Webcam image recognition for solo (room_size=2) and group (4/6/9) classes
  - Theodore (AI) teaching mode and user self-teaching (human leads; Theodore assists)
  - Silhouette / body presence + fused user-absence (grace → class hold)
  - xAI Grok Voice Agent client for natural spoken responses
    (wss://api.x.ai/v1/realtime, mock offline; XAI_API_KEY for live)

Shared promotion
  aoep_shared.vision.silhouette — SilhouetteDetection, estimate_body_presence,
  fuse_face_and_silhouette. Config: XAI_API_KEY / XAI_VOICE_* in AppConfig.

Quick start
  python3 labs/webcam-recognition-suite/scripts/run_lab.py
  python3 labs/webcam-recognition-suite/scripts/run_lab.py --mode self_teach --class-mode group --size 6
  cd labs/webcam-recognition-suite && PYTHONPATH=src:../../packages/shared/src python3 -m pytest -q
