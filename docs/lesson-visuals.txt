On-demand lesson visuals (student ask → screen + audio)
=======================================================

When a learner asks for examples, comparisons, or pictures (e.g. differences
between state driver's licenses), the tutor can return an offline SVG visual
that plays while the audio agent speaks.

What it is
----------
  - Deterministic SVG scenes / two-panel comparisons / short multi-frame
    animation sequences (CSS keyframes).
  - No Stable Diffusion, DALL·E, or paid image API.
  - Built on cert_storyboard sprites + aoep_shared.lesson_visuals.

APIs
----
  POST /api/visuals/generate
    { "question": "...", "language": "en", "answer_text": "", "force": false }
    → { ok, visual: { svg, narration, frames[], sync, ... } }

  Session ask also attaches visual when warranted:
    POST /api/sessions/{id}/ask  → Answer.visual

Web class UI
------------
  ClassRoom shows Answer.visual under the slide storyboard and cycles frames
  while the teacher answer is audible.

Examples that trigger visuals
-----------------------------
  - "Show me the differences between California and Texas driver's licenses"
  - "Compare CA vs NY provisional rules on screen"
  - "Show me a picture of a safe left turn"

Drive Mode stays audio-only (no visuals by design).
