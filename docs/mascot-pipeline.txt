Salareen mascot .glb pipeline
=============================

Goal: produce apps/web/public/mascot3d/Mascot.glb that drops into the
MascotActor3D + MascotOverlay3D renderers with zero code changes.

Drop-in contract (enforced by scripts/validate_mascot_glb.py):
  - glTF 2.0 binary (.glb), <= 2 MB soft budget, <= 5 MB hard.
  - Skeletal rig with at least one skin (deforms with animation).
  - Three animation clips named exactly: "Survey", "Walk", "Run".
  - 5k - 20k triangles. One 1024 x 1024 baseColor texture is plenty.

Picked path for this run:
  AI mesh generation + Mixamo auto-rig + Blender cleanup, with a
  "neutral cute creature" concept (owl / robot / blob / star) so there
  is zero cultural read after the Buddha-fox issue on the Learner Check.

Overview (expect ~2-4 hours end to end, zero prior 3D skills needed):

  1. Generate 2D reference portraits of the creature.
  2. Mesh them into a .obj / .glb with an AI model (Meshy.ai web OR
     Hunyuan3D-2 local on GPU OR TripoSR local on CPU/GPU).
  3. Upload the mesh to Mixamo, auto-rig, download Idle / Walking /
     Running as FBX.
  4. Run scripts/mascot_blender_postprocess.py inside Blender to merge
     the four FBX files into one Mascot.glb with the correct clip names.
  5. Run scripts/validate_mascot_glb.py to prove the contract is met.
  6. Copy to apps/web/public/mascot3d/Mascot.glb and flip MODEL_URL in
     MascotActor3D.tsx + MascotOverlay3D.tsx. Done.


Step 1 - Concept + reference portraits
--------------------------------------

Generate 3 square portraits per candidate concept: FRONT, 3/4 view, SIDE.
Keep the character on a plain white background, standing upright, facing
camera. These are the inputs for the mesh generator in step 2.

Recommended tools (any one is fine):
  - Midjourney v6 / v7 (highest quality humanoids)
  - Nano Banana (fast iteration)
  - Stable Diffusion XL + a character-sheet LoRA (free, local)
  - DALL-E / ChatGPT image mode

Prompt templates (replace <concept> with the one you want):

  owl:
    "a friendly round cartoon owl mascot, standing upright on two short
    legs, big expressive eyes, soft pastel feathers, warm earth-tone
    palette, plain white background, full body, front view, 3D render,
    stylized toy aesthetic, no text, no logo, no accessories"

  robot:
    "a small friendly cartoon robot mascot, rounded chassis, big round
    camera-lens eyes, two short legs, matte warm metal with soft gold
    accents, plain white background, full body, front view, 3D render,
    toy aesthetic, no text, no logo"

  blob:
    "a cute translucent gel blob mascot with two big eyes and tiny arms,
    pastel blue-green gradient, standing upright, plain white background,
    full body, front view, 3D render, soft rim lighting, no text"

  star:
    "a cute cartoon star mascot with a face and two small arms and legs,
    warm gold color with soft inner glow, plain white background, full
    body, front view, 3D render, toy aesthetic, no text, no logo"

For each one, also render:
  "same character, 3/4 view, same lighting, same background"
  "same character, side view, same lighting, same background"


Step 2 - Image -> rigged mesh
-----------------------------

Pick ONE of these three. Meshy.ai is the fastest. Hunyuan3D-2 is the
highest-fidelity open-source model and is what you want if you asked
about "training" the character pipeline on-prem.

Option 2a - Meshy.ai (web, no setup, free tier)
  1. meshy.ai -> "Image to 3D".
  2. Upload the FRONT portrait from step 1.
  3. Pick "Standard" quality + "Enable Rigging" (humanoid auto-rig).
  4. Download as .fbx with textures.
  5. Skip to step 3 - the mesh is ready to animate.

Option 2b - Hunyuan3D-2 (local, needs CUDA GPU with ~16 GB VRAM)
  Open-source text/image to 3D from Tencent. State of the art as of
  2026. Does NOT auto-rig - produces a static mesh you then upload to
  Mixamo in step 3.
    git clone https://github.com/Tencent/Hunyuan3D-2
    cd Hunyuan3D-2
    pip install -r requirements.txt
    python minimal_demo.py --image /path/to/front.png --output mascot.obj
  Then convert .obj -> .fbx in Blender (File > Import > Wavefront, then
  File > Export > FBX) or straight into Mixamo (it accepts .obj).

Option 2c - TripoSR (local, CPU-friendly, lower fidelity)
  Faster + cheaper than Hunyuan3D-2 if you don't have a big GPU.
    git clone https://github.com/VAST-AI-Research/TripoSR
    cd TripoSR
    pip install -r requirements.txt
    python run.py /path/to/front.png --output-dir out
  Produces out/0/mesh.obj.

Training (fine-tuning) one of the open models on YOUR concept:
  Only Hunyuan3D-2 and TripoSR are realistically fine-tunable. Dataset:
  ~20 multi-view renders of the character you want (e.g. generate 20
  variations in step 1 then render each from 8 angles). Training time:
  ~2-4 hours on an A100 for a LoRA-style adaptation. Not needed for
  v1 - the base models are already good enough for a mascot.


Step 3 - Mixamo auto-rig + animations
-------------------------------------

Even if your mesh generator produced a rig (Meshy does), Mixamo's rig +
free animation library is faster and higher quality. We'll use the
Mixamo rig instead.

  1. Go to mixamo.com (free Adobe account).
  2. Click "Upload Character", drop in the .obj / .fbx from step 2.
  3. Mixamo asks you to drop joint markers (chin, wrists, elbows,
     knees, groin). Drop them on the T-posed mesh. Click "Next" twice.
  4. Download the rigged T-pose:
       Format: FBX Binary
       Pose:   T-pose
       Save as: Mascot_tpose.fbx
  5. On the same page, click "Animations" (left sidebar) and search for
     each clip:
       - "Idle"     -> download as Idle.fbx    (In Place: ON, With Skin: OFF)
       - "Walking"  -> download as Walking.fbx (In Place: ON, With Skin: OFF)
       - "Running"  -> download as Running.fbx (In Place: ON, With Skin: OFF)
     "In Place" removes the root-motion forward slide - we move the
     character in Three.js, not the animation.


Step 4 - Blender post-processing
--------------------------------

Install Blender 4.0 or newer if you don't have it:
  macOS:  brew install --cask blender
  Linux:  snap install blender --classic
  Windows: https://www.blender.org/download/

Then merge the four FBX files into one .glb with the right clip names:

  /Applications/Blender.app/Contents/MacOS/Blender --background \
      --python scripts/mascot_blender_postprocess.py -- \
      --mesh ~/Downloads/Mascot_tpose.fbx \
      --idle ~/Downloads/Idle.fbx \
      --walk ~/Downloads/Walking.fbx \
      --run  ~/Downloads/Running.fbx \
      --out  apps/web/public/mascot3d/Mascot.glb

The script does:
  - Opens an empty Blender scene.
  - Imports the T-pose rig as the exported body.
  - Imports each animation FBX, renames its action to Survey / Walk /
    Run, pushes it to the NLA stack so glTF export includes it.
  - Removes the duplicate armatures the animation FBX dragged in.
  - Exports as GLB with skinning + animations + NLA strips enabled.

Optional poly reduction (if validate_mascot_glb.py warns about size):
  Add --decimate 0.5 to the Blender command to halve the triangle count.


Step 5 - Validate
-----------------

  python3 scripts/validate_mascot_glb.py apps/web/public/mascot3d/Mascot.glb

Expected output:
  size:        under 2 MB
  animations:  ['Survey', 'Walk', 'Run']
  skins:       >= 1
  result:      PASS

If it fails on missing clips, open the .fbx in Blender, go to Dope
Sheet > Action Editor, rename the actions to Survey / Walk / Run, and
re-run the post-processor.


Step 6 - Flip the renderer to the new model
-------------------------------------------

In apps/web/app/components/MascotActor3D.tsx and
apps/web/app/components/MascotOverlay3D.tsx:

  - const MODEL_URL = "/mascot3d/Fox.glb";
  + const MODEL_URL = "/mascot3d/Mascot.glb";

Also remove the applyBuddhaFoxStyle(gltfScene) call (and its import)
from both files - your new mesh carries its own baked textures and
accessories, so the Fox-only reskin is no longer needed.

Hot-reload the page. The CSS "art pane" mode (?mascot3d=0) is
unaffected. The Learner Check step stays mascot-free (MASCOT_HIDDEN_
STEPS in MascotActorChoice.tsx), which is correct and intentional -
do not re-add the mascot there.


Troubleshooting
---------------

"Only one clip plays - the other two are missing":
  You didn't push the actions down to the NLA stack. The post-processor
  does this for you. If you edited the .blend by hand, open each action
  in the Action Editor and click the "Push Down" button next to the
  action name.

"The character T-poses and doesn't deform":
  No skinning. In Blender's glTF export dialog, enable
  Data > Armature > Export Deformation Bones Only. Re-export.

"Shows up but is huge or tiny":
  Mixamo exports in centimeters; the Fox base is in meters at 0.012
  scale. In MascotActor3D.tsx, grep for the Fox scale constant and
  adjust the SCALE multiplier (or scale the mesh in Blender before
  export).

"The web dev server 404s on /mascot3d/Mascot.glb":
  Next.js serves everything in apps/web/public verbatim. If the file
  is there and the URL still 404s, hard-refresh the dev server:
  Ctrl-C, then `npm run dev`.
