HOW THE SET IS BUILT
  Default voice rule: pinned voice if we already used one; else the first voice of that gender, alphabetical by short name, in the primary locale (Multilingual voices only if nothing else exists).
  Voices we already used keep their place: en Ava/Andrew, es Dalia/Jorge, zh Xiaoxiao/Yunxi, yue HiuMaan/WanLung, km Sreymom/Piseth, th Premwadee/Niwat, vi HoaiMy/NamMinh, sw Zuri/Rafiki, hi Swara/Madhur.
  10 sentences per language (S01, M01, L01, N01, D01, P01, V01, Q01, S02, M02): the 8 languages with the full 40-sentence set (en es zh vi th km sw hi) reuse their rows exactly;
  all others are machine translations (source 'grok-translation-v1', review_status 'unreviewed'), checked for script, numbers, loops and copied English.
  Translation: xAI Grok (grok-4.20-0309-non-reasoning), one call per language plus one regeneration pass for failed sentences: 72 calls, about 33.5k input and 18.5k output tokens, roughly $0.09 at the model's list price.
  Clips: default female and male voice on all 10 sentences (1500); the 9 character presets on the default female for S01 and Q01 (1350);
  every other voice of the language, one sentence each, id A01 = S01 text (168). Character presets are prosody only (rate, pitch, volume).
  Total planned: 3018 clips in 993 voice folders.
